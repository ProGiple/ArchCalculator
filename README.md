# ArchCalculator

Лёгкий и быстрый консольный калькулятор на **C#**, построенный на парсере математических выражений методом рекурсивного спуска (Recursive Descent Parser). Поддерживает как инженерные вычисления, так и программистские побитовые операции и конвертацию между системами счисления.

## Возможности

* **Два режима работы:**
  * **Интерактивный (REPL)** — запуск без аргументов с историей ввода (`ReadLine.HistoryEnabled`).
  * **CLI-режим (однострочный)** — передача выражения напрямую через аргументы командной строки.
* **Системы счисления:**
  * Ввод чисел с префиксами: шестнадцатеричные (`0xFF`), двоичные (`0b1010`), восьмеричные (`0o77`), научная нотация (`1.5e-3`).
  * Перевод результата (включая дробную часть до 8 знаков после запятой) в любую систему счисления с основанием **от 2 до 36** через префикс `$<основание>`.
* **Полный приоритет операций и ассоциативность:**
  * Унарные операторы (`+`, `-`, побитовое НЕ `~`) и постфиксный факториал (`!`).
  * Правоассоциативное возведение в степень (`**` и `^`).
  * Арифметика (`*`, `/`, остаток от деления `%`, `+`, `-`).
  * Побитовые сдвиги (`<<`, `>>`) и побитовая логика (`&`, `xor`, `|`).
* **Богатый набор функций и констант:**
  * Константы: `pi`, `e`, `tau`.
  * Тригонометрия и гиперболические функции (`sin`, `cos`, `tan`/`tg`, `cot`/`ctg`, `asin`, `acos`, `atan`/`atg`, `sinh`, `cosh`, `tanh`).
  * Конвертация углов (`rad`, `deg`), корни и логарифмы (`sqrt`, `cbrt`, `ln`, `log(x, base)`, `exp`, `pow(x, y)`), округление и сравнение (`abs`, `floor`, `ceil`, `round`, `sign`, `min`, `max`).
  * Вызов функций как со скобками `sin(rad(30))`, так и без них для одного аргумента `sin 100`.

## Зависимости

* **.NET SDK** (рекомендуется .NET 8.0 или новее)
* Пакет **ReadLine** (для истории команд в интерактивном режиме):
  ```bash
  dotnet add package ReadLine
  ```

## Сборка и запуск

```bash
dotnet build -c Release
```

### Интерактивный режим

Запустите приложение без параметров:

```bash
dotnet run
```

Примеры команд в консоли:

```text
> -45+120*(5/3**2^0.5)*sin100/(3&1)-5%2
= -45.73634873128325

> $16 20
= 14 (осн. 16)

> $2 0xFF & 0b101
= 101 (осн. 2)

> $16 10.5
= A.8 (осн. 16)

> sin(rad(30)) + log(8, 2) + 5!
= 123.5
```

Для выхода введите `exit` или `quit` (или нажмите `Ctrl+D`).

### Запуск из командной строки (CLI)

Передайте выражение как аргументы при вызове (рекомендуется оборачивать в кавычки, чтобы shell не интерпретировал символы `&`, `|`, `*`, `^` и `$`):

```bash
dotnet run -- "2^10 + sqrt(144)"
# = 1036

dotnet run -- '$16 255 * 2'
# = 1FE (осн. 16)
```

## Справочник операторов и функций

| Категория | Синтаксис / Имена | Примечание |
| :--- | :--- | :--- |
| **Перевод СС** | `$<2..36> <выражение>` | Выводит результат в указанной системе счисления |
| **Префиксы чисел** | `0x...`, `0b...`, `0o...` | Шестнадцатеричная, двоичная, восьмеричная СС |
| **Арифметика** | `+`, `-`, `*`, `/`, `%`, `**`, `^`, `!` | `**` и `^` правоассоциативны; `!` — факториал |
| **Побитовые** | `~`, `<<`, `>>`, `&`, `xor`, `\|` | Выполняются над целой частью операндов (`long`) |
| **Константы** | `pi`, `e`, `tau` | $\pi \approx 3.14159$, $e \approx 2.71828$, $\tau = 2\pi$ |
| **Тригонометрия** | `sin`, `cos`, `tan` (`tg`), `cot` (`ctg`), `asin`, `acos`, `atan` (`atg`) | Аргументы в радианах; используйте `rad(x)` для градусов |
| **Гиперболические** | `sinh`, `cosh`, `tanh` | Гиперболические синус, косинус, тангенс |
| **Степени и логарифмы** | `sqrt`, `cbrt`, `ln`, `log(x[, base])`, `exp`, `pow(x, y)` | `log(x)` без второго аргумента считает $\log_{10}(x)$ |
| **Утилиты** | `abs`, `floor`, `ceil`, `round`, `sign`, `rad`, `deg`, `min`, `max` | `min` и `max` принимают 2 аргумента через запятую |
